# 第一阶段：完整 Markdown 报告

保持完整专业报告应有的信息密度、推理层次和具体程度。不要因为使用 Markdown 标记而概括、缩短或删除重要事实、证据、原因、影响、行动步骤、适用边界、成功信号和必要话术。

只使用以下内容标记：

- `#`：页面大标题，只出现一次，不含编号。标题必须是对读者当天核心问题和改进方向的自然总结，优先使用“行动总结型”表达，包含最重要的 1–2 条主线，并体现行动方向或关键判断。例如“下一份工作要选对，和孩子沟通要慢一点”。像一个了解读者的人在总结这一天，不要写成报告分类或内容目录。禁止使用“一天录音里的……”“关于……的分析”“今日综合报告”“主线、辅导与边界提醒”等报告腔或关键词拼接式标题；
- 固定的 `## 今天发生了什么，重点改进什么`：先写综合导读，再用 Markdown 表格展示“阶段、发生的事、对应的改进”；
- `##`：一级标题，按真实内容自适应命名，不含编号；
- `###`：二级标题，只在章节确实需要细分时使用，不含编号；
- 普通自然段：承载完整正文分析；
- `>`：逐字稿原文引用，引用内容使用中文引号；
- `-` 或 `1.`：基础列表，只在并列信息或明确步骤中使用；
- Markdown 表格：只用于具有稳定重复字段的比较，不用于装饰。

前端负责标题编号、章节分隔、字号、间距和引用、列表、表格的展示。不要输出其他展示指令，不要使用图片、HTML、代码围栏或额外内容类型。

顶部导读和表格是唯一总览。后续章节必须继续提供证据、原因、影响、判断边界或具体行动，不能只是换句话重复总览。章节按材料价值自由组织，不为完整性凑栏目，不使用机械统一三段式。

有可靠待办时，在相关章节中明确写出，也可以增加 `## 待办清单`；区分明确承诺、可能相关需核实和只是别人讨论的事情。没有可靠待办时省略。最后使用 `## 数据范围与判断边界` 说明覆盖、重复、转写、身份、联网和其他影响判断的限制。
