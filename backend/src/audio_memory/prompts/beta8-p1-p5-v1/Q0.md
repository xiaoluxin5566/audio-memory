以下扣分已按新旧满分比例折算，使用时不得再次乘系数。先从满分起扣，最低为零。每项扣分必须定位到一个实际缺陷，标明规则 ID、维度、分值和影响，并具体写出为了消除该扣分，正文缺少或需要纠正的内容；不能只写“补充分析”“增加细节”“完善建议”。同一缺陷在同一维度只扣一次。若影响不同维度，必须分别说明不同损失。主题整个遗漏时按覆盖规则合并，不拆成许多细小遗漏累计扣分。

事实与证据准确性 factual_accuracy，15 分：
F1 核心决定、身份、关系、金额、日期、岗位、健康安全、重大待办或关键结论错误或凭空补出，改变判断：4。
F2 同类核心事实错误覆盖多处，或错误被用于后续建议和判断：6；特别严重为 8。同一事实不再叠加 F1。
F3 错误合并概念、数据类型或层级关系，导致能力判断、结论或建议错误：3。
F4 错误归因给用户、他人、公司或媒体，把未确认的说话人簇当成用户或具体人物，或把播放当成本人经历或观点：2.5。
F5 关键引语、人物、时间、数量、名称等失真，但不改变核心判断：1.5。
F6 无关紧要细节不精确，且没有用于分析或建议：0.5。
F7 无证据和可理解的推理桥梁，却把心理动机、长期偏好、因果关系或预测写成事实：2。
同一事实错误只选最高适用档。critical 事实错误通常至少扣 6。有证据、推理自然且强度适配的分析与建议不扣事实分。

重要内容覆盖 important_coverage，15 分：
COV1 漏掉当天最重要的决定、承诺、风险、冲突、重大待办或改变整体叙事的事件：3.6。
COV2 漏掉核心主题的重要背景、约束、分歧、后续节点或关键内容消费洞见：2.4。
COV3 漏掉有明确行动价值的普通待办、机会或关系信号：1.2。
COV4 已提到事件，却漏掉会改变其含义的限定、时间、责任归属或结果：1.8。
COV5 只覆盖单一主题，遗漏另一个证据充分且重要的当天主题：3。
同一主题的多项遗漏本质为整个主题未覆盖时，合并扣 3—3.6，不再逐条累计。没有出现、价值低或证据不足的内容不因未写入扣分。

分析深度 analysis_depth，25 分：
D1 重要主题只罗列或复述，没有解释原因、影响、权衡或提供判断结构：5。
D2 核心判断缺少可理解的推理桥梁，存在明显跳跃或矛盾：3.75。
D3 已有直接证据表明存在会改变结论的重要取舍、风险或反例，却完全忽略：3.75。
D4 套话式判断，没有结合当天具体情境：2.5。
D5 把薄弱推测写成确定结论，或用单一片段推出稳定人格、长期趋势：5。
同一主题的“只复述”与“缺少推理链”通常合并扣 5。重要主题完全没有有效分析时，根据影响合计扣 6.25—8.75；这是该主题合并档，不叠加 D1、D2。合理分析不要求穷尽所有反例和替代方案。

建议与行动质量 actionability，30 分：
A1 重要且需要行动的主题只给整理、沟通、准备等方向，没有说明结合当天问题具体解决什么或如何开始：8。
A2 建议缺少必要要素而无法理解或开始执行：4。
A3 建议不解决当天已指出的问题、风险或取舍：6。
A4 看似具体但不现实、越权，或要求用户操控、筛选录音输入：6。
A5 多条建议重复同一动作，未帮助作优先级选择：2。
A_SEARCH_MISSING P2 已明确判定必须搜索，但 P3 没有得到任何已验证来源，导致计划中的行动增益交付物无法完成：4。该项由程序根据实际搜索制品追加，评分模型不得输出。
同一建议空泛且缺执行要素，只扣 A1 一次。重要主题完全没有可用行动方案时合计扣 8—12，作为合并档，不叠加 A1、A2。没有行动空间不扣缺建议分；不因缺模板、指标或完整步骤而机械扣分，只判断能否理解并开始行动。

表达与结构 expression_structure，15 分：
E1 面向用户泄露文件、片段、转写、模型、筛选等内部过程，或用过程替代结论：6。
E2 标题抽象、工程腔、不自然，无法识别重要判断：3。
E3 具备明确结构的三项以上信息仍堆成长段，或使用明显不匹配的形式，明显妨碍理解：3。包括并列结论未用短要点或表格、选项差异未用比较表、事件演进未用时间线或阶段结构、行动责任与验收未用步骤/行动表/清单、风险未同时说明触发条件/影响/处理。只判断正文中确实存在的结构需求，不因简单短事件未使用复杂结构而扣分。
E4 低价值“信号少、无法确认”等填充挤占重点：3。
E5 重复、组织混乱、指代不清或 Markdown 损坏，明显影响阅读：1.5—3。
E6 大面积报告腔、工程腔或抽象隐喻，影响理解：4.5。
同一段的多种表达缺陷按主要问题扣一次，通常不超过 4.5；不同章节重复出现可分别计次。简洁写法、合理删减和个人文风差异不扣分。

区间分值按影响程度选择，并说明为什么取该值；保留两位小数。不得增加无理由的失分或因为“还可以更好”而任意扣分。

合并档的规则 ID 固定为 COV_WHOLE（3—3.6）、D_NONE（6.25—8.75）、A_NONE（8—12）。critical 事实问题若适用基础档不足 6，使用 F_CRITICAL（6—8）并说明严重影响，替代该事实的其他事实扣分；不得把它再叠加一次。

问题等级：
critical：可能严重误导用户的核心事实、身份、健康安全、重大待办或关键结论错误。
major：显著影响报告价值的事实错误、重大遗漏、错误归因、虚假引语、空泛分析或不可执行建议。
minor：不改变核心判断的表达、结构、轻微重复或局部清晰度问题。

score_dimension = max(0, dimension_max - sum(valid_deductions_in_dimension))
raw_total = 五维分数之和。

passed 要求 raw_total >= 75，且无未解决 critical 或 major，必要审核完整，结构与引用硬校验通过。
