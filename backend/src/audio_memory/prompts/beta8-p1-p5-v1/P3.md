P3 是确定性的公开网络检索环节，不再调用模型做二次规划或判断。

输入是 P2 产生的一个明确研究任务：`task_key`、`question`、`purpose`、`public_context`、`source_requirements`、`as_of`、`stop_condition` 和 `source_limit`。程序将这些公开字段合成一个精确查询，对每个任务只调用一次 Kimi Search Pro。

输出只保留搜索服务返回的网页原文片段、标题、URL、站点和日期。程序检查引用是否确实存在于返回的原文片段中，保存原始响应和证据摘录。P3 不用模型常识补齐结果，不把搜索摘要冒充原文，不写卡片或最终建议。

有可追溯原文时返回 `partial`，由 P4 结合完整 Activity 原文和用户目标做最终判断；没有原文片段时返回 `not_found`；工具或服务失败时返回 `failed`。任何空结果都不得伪造来源。
