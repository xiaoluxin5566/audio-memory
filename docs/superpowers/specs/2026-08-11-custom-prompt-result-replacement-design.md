# 自定义 Prompt 结果替换设计

## 目标

将 `exports/custom-prompt-analysis-v2.json` 中由 DeepSeek V4 Pro 生成的 3 张 Event/Insight 卡片，正式替换当前批次在原有 Audio Memory 网页中的可见分析结果。用户继续通过原有信息流和卡片详情查看内容，不再依赖独立临时网页。

## 范围

- 只替换当前最新批次的可见分析卡片。
- 保留旧分析版本和原始转写，不删除历史数据。
- 本次导入不触发模型调用，不更新隐藏用户画像。
- 不改变历史音频、待办、问答和 Prompt 设置的既有行为。
- 不把导出 JSON 作为前端运行时依赖。

## 数据设计

新增一个受控的结果导入入口，将附件 Prompt 的输出转换为后端现有的自主分析数据模型：

- `card_kind`、`scene_types` 作为卡片元数据保留；
- `findings` 转换为自由分析章节，保留类型、置信度和证据 ID；
- `analysis` 转换为正文分析章节；
- `quotes` 转换为现有原句分析；
- `actions` 转换为现有针对性建议；
- 卡片级证据由上述各部分的合法证据 ID 去重汇总。

导入前验证 JSON 结构、句段 ID 和逐字引语。验证失败时不写数据库，当前页面结果保持不变。

导入成功后创建一个新的已完成分析版本和对应卡片记录，并原子切换批次的 `current_analysis_version_id`。旧版本继续留存，便于回滚和对比。

## 页面设计

沿用现有信息流卡片和详情抽屉：

- 卡片标签显示“事件分析”或“深度洞察”；
- 摘要直接展示模型生成的 `summary`；
- 详情按“关键发现 → 深度分析 → 关键原句 → 建议行动”的内容顺序呈现；
- 只有实际存在的内容才显示，不生成空章节；
- 证据 ID 不直接占据正文视觉层级，继续由现有证据与播放能力承载。

视觉上保持当前 Audio Memory 的克制、信息密集风格，不引入第二套页面或独立主题。

## 错误与回滚

- 找不到当前批次、输出不是 `complete`、卡片为空、证据 ID 不存在或引语不逐字时，导入终止且不修改数据库。
- 数据库写入使用单个事务；任何一步失败都回滚。
- 新版本发布后如需恢复，可将批次指针切回旧分析版本，无需重新转写。

## 验收标准

1. 原网页信息流只显示本次 3 张新卡片，不再显示之前的可见卡片。
2. 三张卡片标题、摘要、发现、分析、原句和行动与校验后的 JSON 一致。
3. 卡片标签能区分 Event 与 Insight。
4. 所有证据 ID 均属于当前转写，所有直接引语均为对应句段的连续原文。
5. 刷新页面和重启服务后结果仍存在。
6. 原始音频、转写、旧分析版本及隐藏用户画像均未被删除或更新。
7. 新增转换和发布行为有自动化测试，现有前端与后端相关测试通过。
