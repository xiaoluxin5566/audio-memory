# Audio Memory 视觉升级设计

## 目标

在不改变现有信息架构、页面结构、功能入口和交互流程的前提下，提升首页、信息流、分析详情、历史与设置页面的视觉质量。

界面需要同时传达四个感受：

- 陪伴：用户每天上传音频，AI 持续分析并给出建议；陪伴来自稳定、可靠的日常反馈，而非人格化聊天。
- 沉稳：减少装饰和高饱和效果，让内容与建议成为视觉中心。
- 专业：使用一致的栅格、字体层级、间距、组件状态和证据表达。
- 智能：通过分析状态、声波反馈、内容分类和证据关联表达 AI 能力，而非使用发光球或赛博视觉。

## 范围

### 保持不变

- 顶部导航与主要页面入口。
- 首页左侧模型配置、音频上传与右侧信息流的基本结构。
- 上传、分析中、分析完成和失败恢复流程。
- 信息流的批次概览与分析卡片结构。
- 分析详情中的结论、分析、建议、证据与追问功能。
- 历史与 Prompt 设置的功能结构。

### 允许调整

- 色彩、字体、字号、行高、间距和栅格比例。
- 卡片、按钮、输入框、标签、提示和模态框样式。
- 图标体系、边框、圆角、阴影和背景层次。
- 声波、上传、分析进度与内容出现时的轻量动效。
- 文案的视觉层级，但不改变产品含义。

## 视觉方向

第一轮提供三套真实尺寸视觉方案，均沿用现有页面结构：

1. **温暖科技感（推荐）**：暖灰背景、深墨蓝文字、低饱和蓝紫主色。平衡陪伴、专业与智能。
2. **清晰专业感**：冷白背景、石墨灰文字、深蓝强调。信息密度更高，强调可靠与效率。
3. **柔和陪伴感**：象牙白背景、灰蓝文字、少量鼠尾草绿。更亲近，但保持现代和克制。

每套方案独立展示首页、信息流和分析详情，不使用三屏压缩式展示板。桌面稿采用 1440×1024 真实视口，必要时补充 390×844 移动端首页。

## 设计系统原则

### 色彩

- 页面背景与内容表面保持低对比层次，避免纯白卡片铺满灰底。
- 主色只用于主要操作、当前状态和关键信息。
- 成功、警告和错误均使用低饱和语义色，并配合文字或图标，不单独依赖颜色。
- 不使用大面积渐变、霓虹、高强度光晕或玻璃拟态。

### 字体与信息层级

- 正文基准字号不低于 14px，核心阅读内容使用 15–16px。
- 界面最多使用两个字体家族；中文正文优先使用高可读无衬线字体。
- 标题、结论、证据和辅助信息使用明确且稳定的四级层级。
- 限制长文本行宽，分析详情正文保持舒适阅读长度。

### 组件

- 统一卡片圆角、边框、内边距与悬停状态。
- 上传区域是首页最主要的视觉行动点，但不改动其所在位置与操作方式。
- AI 分析卡片通过标签、结论和下一步形成层级，不增加新的功能模块。
- 原声证据使用统一的时间戳、播放入口和引用样式。
- 所有主要按钮与移动端触控目标不小于 44px。

### 动效

- 动效用于解释状态变化：上传、分析步骤、完成和新内容出现。
- 常规过渡为 150–300ms，并支持 `prefers-reduced-motion`。
- 不使用持续漂浮、无意义脉冲或大面积背景动画。

## 核心页面要求

### 首页

- 保留左侧控制区与右侧内容区。
- 标题语义调整为“你的高级个人分析顾问”。
- 上传区成为最明确的主操作；模型配置视觉降级，但功能与位置不变。
- 空状态说明 AI 将从当天音频中给出洞察与建议，避免营销式功能罗列。

### 信息流

- 保留批次时间线、概览卡片和结果卡片。
- 通过排版、留白和标签提升扫描效率，减少每张卡片视觉同质化。
- 重点强调 AI 结论与可行动建议，时间和来源作为辅助信息。

### 分析详情

- 保留现有内容结构与功能。
- 强化核心结论、建议和原声证据之间的层级。
- 长文采用阅读型排版；侧栏上传区不得干扰正文阅读。

## 验收标准

- 三套方案均保持现有页面结构，用户无需重新学习操作路径。
- 第一眼可以识别上传是首页主操作，AI 建议是结果页主价值。
- 页面不依赖炫目的 AI 装饰也能体现智能能力。
- 1440px 与 375/390px 视口无布局挤压或横向溢出。
- 正文、按钮、表单和状态提示满足基本可读性、对比度和触控要求。
- 视觉语言能支持长期高频使用，不因高密度装饰造成疲劳。
