# 快速转写风险片段质量门设计

## 目标

保持 `whisper-large-v3-turbo` 的全量句段级快速转写；只对疑似“字幕式幻觉”或不可信片段进行词级二次精转写，避免不可信文本生成卡片、待办或画像。

## 已知事实

- 主转写已使用 `word_timestamps=False`，即句段级时间戳。
- 词级时间戳只适合少量片段的精转写，不适合全量开启。
- Phase 0 的真实长音频基准中，预处理占 Whisper 耗时 16.1%，选择 Plan A；本期不为预处理引入流式流水线。

## 规则

### 0. 文本标准化与相似度

所有重复和相似判断使用同一接口 `normalize_transcript_text(text) -> str`：Unicode NFKC 规范化、全角转半角、英文小写化、去除标点与空白、中文数字与阿拉伯数字归一为同一形式。相似度采用归一化编辑距离：`1 - levenshtein(a, b) / max(len(a), len(b))`；两者均为空时不判相似，高风险阈值固定为 0.90。

### 1. 硬性不可信

满足任一条件即拒绝，不进行二次精转写：

- 应用 0.3 秒边界容差后，片段与 VAD 语音区间的重叠仍少于 0.5 秒，且覆盖该句段的比例低于 30%。
- 时间戳不递增、越出所属音频窗口或文本为空。
- 同一片段在边界合并后出现无法解决的时间冲突。

拒绝片段不进入任何用户结果、卡片、待办、画像、检索或分析输入。后端只保留不含文本的内部质量记录：原始时间范围、拒绝原因和风险状态；原始音频仍可用于重新转写。C 端不新增逐字稿或过滤片段入口。

### 2. 高风险

满足任一组合则进入词级二次精转写：

- 标准化后相同或高度相似（相似度至少 0.90）的句段，在 30 秒内出现至少 3 次。
- 单一片段中长度至少 8 个汉字/字符的短语连续重复至少 3 次。
- 非首段满足 `当前片段开始 - 前一片段结束 > 10 秒`，且与前一片段标准化文本相似度至少 0.90。该间隙必须使用 VAD 解码时缓存的波形能量二次确认；不得重新全量解码音频。首段之前的静音不触发此规则。
- 片段持续至少 1.5 秒，按 VAD 占空比折算的有效语音时长计算后，中文等无空格文本每秒超过 14 个字符，或任意语言每秒超过 7 个词，且同时存在重复模式。

二次精转写后的复检只检查文本重复和语义异常，不再复用原始硬性时间戳规则。复检通过则替换原句段；失败或仍重复则转为 `POST_EDIT_FAILED` 并隔离。

### 3. 中风险

仅记录、不主动精转写：极短断句、一次轻微重复、说话人标签不稳定，或模型输出提供了异常的无语音/对数概率指标。中风险以可靠性权重 0.6 传给下游，不允许分析阶段回溯音频或重新开启精转写队列。

首版能力门槛显式如下：

- 一次轻微重复已启用 0.6 权重。
- “极短”尚无经标注数据批准的时长/字数阈值，不在首版自行选取常量；只有离线标注证据稳定后才能启用。
- 当前说话人分段只输出文件内统一标签，未输出可校准的“标签稳定度”；在上游提供有稳定语义的数值之前，该信号不参与权重判定。
- MLX 若对一个未拆分的快速句段返回有限数 `no_speech_prob` / `avg_logprob`，则分别持久化到 Transcript 的可空数值列；缺失、非有限数、越界概率或被说话人分段拆成多段的输出统一记为 `NULL`。这些列不记入日志、不向用户输出，也不单独触发删改。
- VAD 可用性与原始语音区间分开持久化。VAD 成功但没有检出语音时，仍执行 `no_vad_support` 硬拒绝；VAD 本身失败时，可用的回退转写降为 0.6 `vad_unavailable`，但文件越界、非递增时间、空文本和跨段冲突仍硬拒绝。

### 4. 状态机

风险状态只允许：`REJECTED`、`HIGH_RISK_PENDING`、`POST_EDIT_PASSED`、`POST_EDIT_FAILED`。原始硬性校验只产生 `REJECTED`；高风险进入 `HIGH_RISK_PENDING`；二次精转写后只能进入 `POST_EDIT_PASSED` 或 `POST_EDIT_FAILED`，不得再次排队。

若 MLX 稳定返回 `no_speech_prob` 或 `avg_logprob`，先记录原始指标用于调优，不在首版用单一阈值硬拒绝。只有基准音频标注与 ROC 结果证明阈值可用后，才能升级为拒绝规则。

## 数据流

1. VAD 与句段级 Whisper 生成候选片段。
2. 风险门依据时间、VAD 映射和文本模式标记每段。
3. 硬性不可信段隔离；高风险段加入有界精转写队列。容量为 `max(10, ceil(总片段数 × 5%))`，超出容量的片段降为中风险，不精转写，并记录错误级诊断。
4. 精转写成功且通过复检的文本替换原段；失败或仍异常的文本标记不可信。
5. 分析输入只包含通过风险门的片段；被隔离文本不进入任何用户可见结果。

## 约束

- 不向用户展示 VAD、词级时间戳、置信分数或技术处理模式。
- 不修改 Whisper 模型，不关闭说话人分段。
- 每个原始句段最多精转写一次；精转写失败不重试，避免长音频放大耗时。
- 模型若未稳定提供概率指标，概率仅作加分信号，不能单独决定删改文本。
- 全量路径在代码和测试中锁定 `word_timestamps=False`；仅风险队列允许 `True`。
- 风险门与二次精转写带来的总墙钟时间增幅不得超过全量快速转写的 20%。
- 输出结构包含 `risk_state`、`is_reliable` 与下游 `reliability_weight`；前端不展示技术状态。
- 输出结构化 `risk_gate_metrics`：总片段数、硬拒绝数、高风险入队数、队列溢出数、精写通过数和精写失败数，不记录文本内容。

## 验收

1. 静音区文本、时间戳损坏文本均不进入分析输入。
2. 三次重复文本会触发一次词级精转写；通过复检时替换原文本。
3. 精转写仍重复的片段不进入任何用户结果、卡片、待办、画像、检索或分析输入；只保留不含文本的内部质量记录。
4. 正常口语的单次重复、短停顿不会触发精转写。
5. 全量快速转写仍不请求词级时间戳；仅风险队列请求一次。
6. 高风险片段超过队列容量后降为中风险，额外耗时不超过快速转写基线的 20%。
7. 参数调优使用 Phase 0 代表性音频建立人工标注集，比较 0.90 相似度、14 字符/秒及候选概率阈值的精确率、召回率和 ROC；在证据形成前不得把概率值设为硬拒绝条件。
