# Beta 8 80k 索引分片实施计划

1. 用回归用例固定单张工作沟通卡可引用超过 2,000 个片段，更新验收清单的 Prompt 和规则指纹。
2. 先为分片合并写失败用例：主范围裁剪、稳定的跨片合并、冲突拒绝、嵌入事件父 ID 重写和全量覆盖。
3. 实现纯本地合并器，不在合并阶段调用模型。
4. 用真实 6,373 段逐字稿离线生成三个连续主范围，验证每段恰好属于一片，并校验中间已有请求可安全复用。
5. 运行 Beta 8 全量本地回归。所有本地检查通过后，仅补发前、后两个索引请求。
6. 合并三个索引并校验 6,373 段完整覆盖，再用全量逐字稿和全日索引运行统一 V1、初审、编辑审核、搜索、修订和终审。
7. 保存请求次数、token、持久化状态、最终产物和范围说明；不提交、合并、发布或运行 ASR。
