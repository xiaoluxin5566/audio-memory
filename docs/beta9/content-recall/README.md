# beta9 内容回溯

当前定稿功能基线为 **音频 AON-RRC v1**，于 2026-11-11 确认。后续变更以 [RRC v1 登记清单](rrc-v1/release.json) 为版本对照。

## 冻结行为

沿用 V9-4 父子事件。将同一事件归属范围内的连续发言每 64 段切片，为原文建索引。查询时先判断事件、时间、人物、地点，必要时接续用户澄清。限定范围内使用 BM25 和查询向量余弦排名，经 RRF 融合后首轮最多读取 10 片。ReAct 最多五轮取证，独立回答阶段使用完整对话和原文证据包。

## 测试依据

Sheet2 共 410 题，274 道直答、136 道澄清。冻结答卷由原批 349 份与修复重放 61 份合并。公司模型同口径评分为 325/410（79.27%），其中直答 221/274，澄清 104/136。最终证据完整 302/410。同题方案3多轮版为 326/410，保留作实验对照。功能定稿表示版本选择，不表示线上部署完成。

## 复核范围

本目录提供原批、澄清修复、恢复及评分阶段的源码快照和三份实际提示词。release.json 保存完整测试快照的 SHA-256，包括由原实验环境保管的输入、索引清单及答卷指纹。运行源码需在原项目目录结构中配套公司接口、运行依赖及经授权的语料和索引。
