## 本轮已修复

### 1. 恢复 Beta 版本的 DeepSeek V4 Pro 单模型约束

代码一度把 `deepseek-v4-flash` 重新加入可选模型，导致全量后端 4 项测试失败，也违背既有 Beta 模型策略。现已移除 Flash 选项，保留 `deepseek-v4-pro`。

### 2. 正确保留 P4 部分初稿

多张卡片写作时，如果后续一张 P4 失败，原实现虽然保存了先前卡片，却仍把整个结果标为 `stopped`。现已在每张卡完成后持久化 `draft_incomplete` 或 `draft_ready`，后续 P4 失败时能够区分“部分初稿”和“没有初稿”，并新增回归测试。

### 3. 搜索来源去重与正式来源身份兼容

P3 的三个聚焦搜索可能重复返回同一个官方页面。原实现会让重复页面多次占用 `source_limit`，从而挤掉其他有效来源；同时使用的临时来源 ID 不符合正式发布器要求。现已按规范化 URL 生成稳定来源 ID，并在合并三个搜索结果时去重、重映射 finding 引用，保留来源名额给不同页面。

### 4. 将输入模板与评分细则纳入链路身份

原固定规则哈希绑定了 P1–P5 和七场景 Prompt，但没有绑定 `INPUT-TEMPLATE.md` 与 `Q0.md`。修改输入协议或评分细则并更新清单后，旧授权和旧断点可能仍被误判为兼容。现已把两项文件哈希纳入固定规则哈希，并增加精确回归测试。
