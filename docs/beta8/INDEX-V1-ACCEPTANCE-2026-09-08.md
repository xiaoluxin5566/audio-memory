# 索引与 V1 内容覆盖验收（2026-09-08）

## 本次修复

- 工作沟通必须由同一个主会话完整覆盖标注范围；数量相同、只覆盖一句、漏头漏尾和中间断段均不能通过。相邻范围可以合并覆盖。
- 媒体标注必须被媒体类型的主会话或嵌入事件覆盖；第三方案例须保留第三方案例类型与表达属性；家庭交流不能因被归入一个巨大的媒体区间而通过。
- 以上内容检查接入真实验收入口，每次生成独立、0600 权限的 `index-acceptance-*.json`。检查失败仍保存结果并停止，不进入 V1。
- `embedded_events` 包括活动内部先后出现的独立事实，不要求声音同时发生；复杂会话需要事实目录，不能只留下笼统标题。没有嵌入事实时可以是空数组，没有数量配额。
- 两个活动之间的其他活动或无效片段必须有相应 block；不存在逐字稿片段的静音不虚构活动。片段归属不等于音频时间被连续活动占满。
- V1 引用父会话不等于处理了内部全部事实；必须回读完整逐字稿，允许引用父会话及准确片段来表达索引未细分的内容，不伪造 ID。
- `build_v1_fact_review` 生成事实、相关卡片、直接证据引用和省略记录对照；引用命中本身不判语义通过。

## 验收口径

| 项目 | 自动检查 | 阅读核验 |
| --- | --- | --- |
| 主覆盖 | 规范化范围、片段真实性、排除账本 | 真实活动边界，其他活动是否被吞并 |
| 工作沟通 | 数量、一一对应、完整范围 | 独立联系动作与跨文件续接证据 |
| 媒体 | 范围与媒体属性 | 不同内容可定位、媒体观点不冒充用户观点 |
| 第三方案例 | 范围、事件类型、表达属性 | 主体是谁、案例用途、是否写成用户状态 |
| 非工作内容 | 已标注家庭内容保留为非工作交流 | 午餐、家庭、职业选择等内容是否遗漏 |
| V1 | 七场景、索引引用与省略闭包、真实 ID、正文结构 | 每项议题、主体归属、独立帮助价值、低价值内容是否乱出卡 |

Ground Truth 仅进入验收端，不提供给生成模型。不能按某个样本的“5 次”或非零嵌入数量写生产特判。自动结果通过后，`semantic_review_status` 仍为 `pending`，必须另存阅读核验结论，不能宣称语义质量已经通过。
