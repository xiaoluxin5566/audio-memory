清除所有历史数据？

此操作会永久删除本地历史数据，无法恢复。删除完成后，首页将回到“先上传音频”的默认状态。

将被删除
  • 所有已上传的音频文件与转写全文
  • 所有模型生成的卡片、详情和完整问答
  • 全局待办与由音频建立的个人画像

不会删除：模型厂商与 API Key 配置、已提交的“意见反馈”记录。

清除规则：这是不可恢复操作，点击入口后需在弹窗中再次确认。系统在删除前停止正在进行的分析任务，删除数据库中的历史记录和本地音频目录，保留 API Key 配置与用户主动提交的意见反馈。
首页导航与隐藏画像规则符合预期个人画像不向用户展示，但仍在后台参与推荐与建议生成。
